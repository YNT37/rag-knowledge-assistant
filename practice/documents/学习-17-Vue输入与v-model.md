# Vue v-model与问题输入状态

适用：Vue 3.5.44、文本输入框。整理日期：2026-10-23。

文本输入框的v-model把控件当前值与关联的可写状态连接。用户输入时更新状态，脚本改变状态时也会更新控件；不需要自己查找DOM再读取输入值。

普通文本框的同步基于value属性与input事件，通常在输入时同步，而不是必须等失去焦点。中文输入法组词期间存在组合输入过程，应在确认组词后检查最终值。

模板顶层ref可以自动解包，绑定时写状态名。初始值由关联状态提供，不应再用另一个静态value与其争夺初始值。

输入question只会更新被绑定的问题状态，不会自动把answer改成同样内容。把当前问题赋给回答是另一次程序操作，不等于建立持续的输入绑定。
