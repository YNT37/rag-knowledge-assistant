# Python函数、参数与返回值

适用：Python 3.12。整理日期：2026-10-23。

Python函数把一段可重复的处理命名。定义中的参数名是形参，调用时给出的对象是实参。普通函数调用时执行函数体，return结束本次调用并将结果交给调用方。

print用于输出到终端，不等于把数据返回给调用方。函数没有执行带值的return时，结果为None。返回None也可能已经修改了输入对象，不能仅凭返回值判断是否发生操作。

筛选列表时，要先遍历全部元素，再返回结果列表。把return放进循环体可能导致处理第一项后就提前结束；返回位置由业务目标决定，不是由变量名决定。

函数形参是函数内部的局部名称。修改共同引用的列表或字典内容，调用方可能看见变化；只给形参重新赋一个空列表，不会自动替换调用方原有名称的绑定。
