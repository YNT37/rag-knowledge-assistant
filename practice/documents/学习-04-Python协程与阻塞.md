# Python协程、await与阻塞

适用：Python 3.12。整理日期：2026-10-23。

Python中用async def定义协程函数。普通调用协程函数先得到协程对象，不会仅因这次调用就执行函数体；需要通过await或事件循环调度驱动它运行。

await等待可等待对象的结果。在真正需要等待时，它可以让其他任务获得执行机会，但不是每次await都保证切换到别的任务。

先await任务A，再创建并await任务B，通常仍是顺序等待。想让两个独立等待过程交错推进，需要显式安排并发，不能只靠在函数前加async关键字。

异步函数中的同步阻塞操作仍会阻塞所在执行线程。async不会自动把普通阻塞调用变成非阻塞调用。并发表示多个过程可交错推进，也不等于CPU代码必定在多个核心同时执行。
