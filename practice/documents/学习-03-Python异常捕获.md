# Python异常类型、try与except

适用：Python 3.12。整理日期：2026-10-23。

Python的try包住可能失败的执行路径。发生异常后，解释器寻找能够匹配该异常类型的except分支；该路径中异常之后的普通语句不会继续执行。

except ValueError as error中的ValueError是要匹配的异常类型，error是接收这次异常实例的局部变量。as不是给异常类型改名。如果不需要读取异常对象，可以省略as及后面的变量。

异常能否被捕获，既取决于类型是否匹配，也取决于出错语句是否处于对应try保护的路径。错误如果发生在try之前，后面的except不会捕获它。

数据库SQL语法错误与完整性约束失败是不同问题。不要看到数据库报错，就假定都能由sqlite3.IntegrityError处理。应先读实际异常类型、出错语句和执行位置。
