# Vue ref、value与类型推断

适用：Vue 3.5.44、TypeScript 6.0.3。整理日期：2026-10-23。

Vue的ref保存可追踪的内部值。script中通过.value读取或修改内部值，模板中顶层ref通常自动解包，可以直接用于文本插值或绑定表达式。

const固定变量绑定，不代表ref容器内部属性不能修改。修改内部值后，Vue会安排依赖它的模板更新；赋值与实际DOM更新不是同一个同步瞬间。

ref是泛型函数，即使没有显式写类型参数，也可以根据初始值推断类型。字符串、布尔值和含字符串元素的数组都常能推断，不是只有数组才使用泛型。

空数组没有元素表达未来要放的对象结构，因此本项目显式指定RagSource数组类型。允许来源对象或null的选中状态也应表达这两种值。两个分别建立的ref不会因为业务相关而自动同步清空。
