# Vue v-for、item、index与key

适用：Vue 3.5.44、当前问答来源列表。整理日期：2026-10-23。

Vue的v-for根据数组逐项生成元素。item是当前数组元素的局部别名，index是可选的当前位置别名，从0开始。数组为空时不生成来源行。

来源项是对象，文件名应取item.source，块编号应取item.chunk_id。index是数组位置，不能当成后端返回的真实块编号。

:key动态绑定供Vue对应同级节点，key本身不会作为编号显示。通常需要稳定且唯一的业务标识；文件名并不一定逐项唯一，相同文件不同块和重复来源都可能存在。

当前来源列表只显示本次响应的文字，可以按已约定方式用位置区分行。以后增加重排、行内编辑或组件状态，需要重新选择稳定身份，不能把index推广为所有列表的通用方案。
