# Python列表、字典与对象引用

适用：Python 3.12。整理日期：2026-10-23。

Python列表按顺序保存多个值，字典通过键保存一条数据的字段。列表下标从0开始，下标是位置，不是业务ID。列表越界会产生IndexError，字典缺少指定键会产生KeyError。

other = results不会复制列表，而是让两个名称引用同一个对象。通过其中一个名称修改列表内共同引用的字典，另一个名称也能观察到改变。

other = []创建新的空列表，只改变other的绑定。results仍指向原来的列表，原列表不会因此被清空。应区分修改对象内容与给名称重新绑定对象。

is判断是否为同一个对象，==比较值或内容。两个分别创建的列表可以内容相等但不是同一对象。不要用整数或短字符串缓存的偶然表现推导一般对象身份规则。
