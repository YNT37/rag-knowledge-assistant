# HTTP请求、响应、Content-Type与JSON

适用：HTTP语义与浏览器常用接口。整理日期：2026-10-23。

HTTP请求由客户端发出，包含方法、URL、请求头以及可选的请求体。HTTP响应由服务端返回，包含状态码、响应头以及可选的响应体。

路径通常定位资源，查询字符串常用于筛选或分页，请求体可以承载结构化提交。具体字段放在哪里必须遵守接口声明，不能靠变量名字推断。

Content-Type说明消息正文的媒体类型。发送JSON正文时，接口通常使用application/json，并把程序内的数据序列化为JSON文本后传输。

JSON是文本格式，不是浏览器中的JavaScript对象，也不是服务端内存中的Python字典。接收方先解析传输文本，再取得本语言的数据值；解析成功不等于字段结构已经满足业务要求。
